# VitalSync Health Planner

A modern and interactive health event planner web application designed to help users manage their daily health routines.

## Features
- Add and manage health-related events
- Categories: Doctor, Medication, Exercise, Diet, Mental Wellness, Water Intake
- Dashboard (Today / Upcoming / Completed)
- Mark events as completed
- Smart time-based reminders
- Responsive glassmorphism UI
- LocalStorage support (data saved in browser)

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)

## How to Run
1. Download or clone the repository
2. Open `index.html` in any browser
